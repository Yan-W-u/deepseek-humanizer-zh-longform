# deep-AI-feel-skill

一个给中文小说"去 AI 味"的 Skill。

单文件，零依赖。装进任何支持 Agent Skills 的编辑器就能用。

## 它解决什么

AI 写的小说有个通病：不说人话。

情绪直接告诉你："她感到无比悲伤。"动机替你总结："因为他从小就……"每段结尾还得升华一下。这些不是词汇问题，是结构问题，换同义词救不回来。

这个 Skill 干两件事：找出这些痕迹，然后改掉。

## 安装

    npx skills add Yan-W-u/deep-AI-feel-skill --global

也可以手动把 SKILL.md 放进工具的 skills 目录。

## 用法

两种模式。

**改写（默认）**

    /deep-ai-feel-skill 润色这段
    /deep-ai-feel-skill 把 第三章.md 的 AI 味去掉

**只检测，不动稿**

    /deep-ai-feel-skill 检测这篇的 AI 痕迹

检测模式出一张表，逐条列出命中的规则、原文片段、严重度，再给五个维度打分：具体性、节奏、克制、信息密度、声音，满分 50。

40 分以上基本是人的稿。25 到 39 分是混合稿，得逐条改。低于 25 分，典型 AI 腔。

## 规则概览

五组，按信号强弱排：

| 组 | 管什么 | 例子 |
|---|---|---|
| A 说而不是演 | 情绪直述、心理旁白、替读者总结动机、段尾升华 | "她感到无比悲伤" |
| B 修饰膨胀 | 形容词三连、程度副词、比喻滥用、四字格排比、宏大意象 | "无尽、苍凉而孤独的荒原" |
| C 节奏句式 | 句长均匀、排比三连、对称对比句、"的"字堆叠 | "不是X，而是Y" |
| D 结构模板 | 段落等长、开场景描套路、对话过度功能化、破折号滥用 | 每段都五到六行 |
| E 残留痕迹 | 助手腔、说明文腔、自我叙述 | "希望这段对你有帮助" |

A 组单次命中就改。B、C 两组要同一段里反复出现才动手。

## 两条底线

一，只改"怎么讲"，不改"讲了什么"。人物、事件、因果、设定、时间线，一个都不动。

二，能补感官和动作细节，不能补情节。把"她很害怕"改成她攥紧门框、听见自己吞口水的声音，可以。给她加个弟弟，不行。

## 不适用的情况

引文、人物故意这么说的台词、方言、信件奏折这类文中文体，不动。

网文的爽点和章末钩子是体裁约定，不是 AI 味，别删。

2022 年 11 月之前的旧稿不是 AI 写的。
