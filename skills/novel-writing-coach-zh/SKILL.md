# 中文长篇小说写作教练

教的是"怎么写才对"，不是"写完怎么补救"。补救那一半在 [deep-ai-feel-skill](../deep-ai-feel-skill/SKILL.md) 和 [deepseek-humanizer-zh-longform](../deepseek-humanizer-zh-longform/SKILL.md) 里。两个 skill 共用同一套语言标准，所以写作时就守住这些标准，稿子自然不带 AI 腔。

## 三条总原则

1. **先想清楚这个故事要证明什么。** 说不清楚，后面的结构、人物、场景都会飘。
2. **每一场戏都要有价值转变。** 一场戏结束时，某个会翻转的东西（信任与怀疑、安全与危险、亲近与疏远）必须朝一个方向动过。
3. **把判断留给读者。** 情绪、动机、结论能靠动作和细节演出来的，就不要写出来。这是"没有 AI 感"的根，也是"写得好"的根。

## 先定位，再动手

稿子读着不对，**先别改句子**。按下面的顺序问一遍，问题在哪一层就在哪一层解决：

| 症状 | 在哪一层 | 去哪 |
|---|---|---|
| 故事本身不成立：激励事件太软、对手太弱、欲望不明确 | 结构与人物 | [references/story.md](references/story.md) |
| 这一段读完了什么都没变 | 场景与节奏 | [references/story.md](references/story.md) |
| 台词都一个腔、把该说的直说了、信息太满 | 对话 | [references/dialogue.md](references/dialogue.md) |
| 不知道这是谁在讲、该展示却讲述、细节没意义 | 叙述与视角 | [references/pov.md](references/pov.md) |
| 句子不顺、读起来累、节奏平 | 语言 | [references/language.md](references/language.md) |
| 知道有问题，但不知道从哪下手 | 修改流程 | [references/revision.md](references/revision.md) |

**最容易犯的错**：拿句子层面的功夫去修结构层面的问题。把一段本来就多余的戏写得再漂亮，它还是多余的。

## 三种模式

### plan 动笔前搭建

用户说"构思""搭大纲""设计人物"时：

1. 先逼出一句话：这个故事想证明什么？用"某某是值得的，因为什么"的句式写出来。
2. 照 [story.md](references/story.md) 的七个关键步骤走一遍：弱点与需求、欲望、对手、计划、对决、自我揭示、新的平衡。
3. 每个关键人物填四角：主角、对手、盟友、假盟友，各自对这个道德问题给出一种答案。
4. **产出几句话或一张表，不是几十页设定。** 这几句话说不清，就是不成熟，不要往下写。

### draft 落笔时指导

用户说"这段怎么写""写不下去了"时：

1. 先判断这一段的**价值往哪个方向动**，动不了就说明这段可以不写。
2. 用"进场晚，退场早"切：从最尖锐的地方进，在张力最高处收，前后过渡让读者自己补。
3. 逐句按 [language.md](references/language.md) 的尺子写：主干立稳、动词具体、形容词吝啬、长短句交替。
4. 对话按 [dialogue.md](references/dialogue.md)：先想人物这一刻要什么、为什么不肯直说，台词就带上潜台词了。
5. 定视角点，交代清楚"这是谁在看"（[pov.md](references/pov.md)）。

### diagnose 成品稿诊断（默认）

用户说"帮我看看""改稿"时：

1. **先通读，先分层，不动笔。**
2. 按上面的定位表定位到层，输出：问题在哪一层、证据片段、建议怎么改。
3. 只改用户指定或同意的部分。
4. 句子层的落点与去 AI 味规则一致；改完对照 [deep-ai-feel-skill](../deep-ai-feel-skill/SKILL.md) 的规则表自检一遍。
5. 装了 `ai-feel-checker` MCP 的话，句长分布、标点比例、高频词直接取数，不要靠估。

## 与去 AI 味 skill 的分工

| | 管什么 | 什么时候用 |
|---|---|---|
| 本 skill | 怎么写才对：结构、人物、场景、对话、视角、句子基本功 | 动笔前、落笔时、改稿定位 |
| deep-ai-feel-skill | 已经写歪的怎么改回来：A–F 组通用 AI 痕迹 | 拿到成稿，逐条去味 |
| deepseek-humanizer-zh-longform | DeepSeek 特有的口癖：DS1–DS13 | 稿子明确是 DeepSeek 写的 |

**衔接点**（同一个判据，两处都在用，不要当成两套规则）：
- "展示与讲述"是这里的核心，也是去味版 A 组（说而不是演）的来源。
- "人物声音"就是去味版的 D6 / DS9（对话同腔）。
- "视角漂移""语体统一"对应去味版 DS11（语域漂移）。
- "虚动词与被动""承接断裂""欧化句式"是句子层的基本功，去味版 C 组另有对应条目。

## 来源

骨架取自罗伯特·麦基《故事》、约翰·特鲁比《故事写作大师班》、詹姆斯·斯科特·贝尔《如何创作炫人耳目的对话》、珍妮特·伯罗威《小说写作：叙事技巧指南》，中文句子部分取自叶圣陶、夏丏尊《七十二堂写作课》。本 skill 是对这些公开框架的归纳与转述，概念名沿用通行译名。想要精确到字句，仍应回到原书。
